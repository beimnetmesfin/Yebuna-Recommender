#Yebuna Recommendation system

A production-oriented content-based recommendation system built with

-Python
-Sentence Transforms
-FAISS
-Pandas/Numpy
-FastAPI

## project structure
- `app/` -recommendation system logic
- `data/` -local developments datasets
-`models/` -generated model aritfacts
-`notebooks/` -experiments
-`api/` -HTTP API
-`tests/`-automated tests
